# Soundmixer-Copilot-optimised

Optimierte Projektkopie mit einer einzigen Volume-Logikdatei.

## Inhalte

- `/gui_config.py` – GUI zur Zuordnung von Reglern zu Apps/Prozessen
- `/volume_logic.py` – zentrale Laufzeitlogik für serielle Eingaben und Lautstärkesteuerung
- `/load_app_mapping.py` – Laden der `config.csv`
- `/config.csv` – aktuelle Regler-Zuordnung

## Hinweis

Diese optimierte Version enthält bewusst nur **eine** Volume-Logikdatei (`volume_logic.py`).
